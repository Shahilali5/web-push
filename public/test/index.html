In-Page JavaScript Push Sender

Send notifications right from your own frontend JavaScript:

// Trigger a push to all visitors on your website WebPush.send({ title: 'Flash Sale Live!', body: '50% off all courses for 2 hours.', url: 'https://mysite.com/courses', buttons: [ { action: 'close', title: 'Later' }, { action: 'open', title: 'Enroll Now ↗', url: 'https://mysite.com/courses' } ] });
